The first release of **seihai-listserver**, the Seihai project's Graal listserver. It gives classic Graal clients (1.41 to 3.x), the Seihai client and RCs their server list, and lets gservers register and check accounts. It is written from scratch in Rust (MIT or Apache-2.0).

## What it does

- **Every client list shape:** the silent 1.41 rev 1 reply, 2.00/2.05 (shape A), 2.17 (shape B), 2.19 to 2.21 (gen 4), 2.22, 2.31 and 3.x (gen 5), and the RC list.
- **Gservers** register, update their player lists and check accounts (`VERIACC2`). An entry is dropped when its link closes or goes quiet.
- **Accounts** are kept in an argon2id file (`add-account`), never as passwords. Without an accounts file the list is open, which suits a lab.
- **Gserver allow-list:** with `gservers` set, only listed addresses that send the right HQ password can put a server on the list.
- **Hidden servers:** a gserver at HQ level 0 appears only on the RC list.
- **Seihai secure login (`SEI00001`):** Seihai clients get the list without the account or password crossing the wire in the clear. The link from seihai-gserver is encrypted the same way. Real Graal clients keep the classic login.
- **Limits and upkeep:** a cap on failed logins per address, config reload on file change (and `SIGHUP` on Unix), and a periodic status line.

## Tested with

- Loopback shape tests for every list shape, plus Seihai's own list client.
- A lab run on 2026-11-04: the GPL fork (seihai-gserver-v2) and seihai-gserver both register, and Seihai's 2.05, 2.17, 2.22 and 2.31 profiles list them with and without the allow-list. Real 2.05 rev 2, 2.17.1, 2.22 and 2.31 clients under Wine list the fork. See `docs/lab/2026-11-04-fork-loopback.md`.

## Not in this release

- The RC list over Seihai's secure login, and a seihai-rc test that logs in through this listserver. Those come with a later release.

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64). Each holds the program, `README.md`, the licences and `seihai-listserver.sample.toml`.

```
seihai-listserver sample-config > seihai-listserver.toml   # then edit it
seihai-listserver
```

With no config it listens on `127.0.0.1`: gservers on port 14900, clients on 14921 to 14923. `README.md` explains hosting for other machines. On macOS, the first start may need right-click → Open, because the build is not signed.
