A maintenance release of **seihai-listserver**, built on seihai-core v0.8.0 (main was on v0.7.2). There is no change for real Graal clients' lists.

## What changed

- Built on seihai-core **v0.8.0**, the core the rest of the suite releases on (3D version profiles, the GS2 compiler at official parity). The listserver's own code did not need changes.
- Profile and buddy text files, and one-shot SQLite imports, accept LF and CRLF records, keeping every field byte, profile escape and buddy order.
- One-shot SQLite profile and buddy imports wait while their text sources are missing, so a later restart can import a newly created or restored source.
- New machine IDs are refused once the table's ID range is used up, before an unreadable row is written. Existing IDs still match and gain keys.
- Real-file SQLite tests for reopening, import-once records, and keeping populated data when a newer schema is refused.
- The release has a `SHA256SUMS` beside the archives.

## Tested with

- `cargo test` and `cargo clippy --all-targets -- -D warnings` on Linux and Windows in CI.

## Download and run

The same as v0.1.0. Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64). Check it against `SHA256SUMS`.

```
seihai-listserver sample-config > seihai-listserver.toml   # then edit it
seihai-listserver
```

On macOS, the first start may need right-click → Open, because the build is not signed.
